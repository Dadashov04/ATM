# Bankomat — ATM Desktop Application

A desktop application developed using C# Windows Forms and Microsoft SQL Server.

## Technologies

- C#
- Windows Forms (WinForms)
- Microsoft SQL Server
- ADO.NET / DataSet
- Visual Studio

## Overview

Bankomat is a desktop application developed as a practical C# project. It combines a Windows Forms user interface with SQL Server database integration.

The project demonstrates desktop application development, database connectivity, and working with structured data in a relational database.

## Project Structure

- `Form1.cs` — application logic
- `Form1.Designer.cs` — Windows Forms interface
- `Program.cs` — application entry point
- `App.config` — application configuration
- `BankomatDataSet` files — database-related DataSet components

## Setup and Configuration

1. Install Visual Studio with .NET Framework development tools.
2. Install Microsoft SQL Server.
3. Open `BANKOMAT.sln` in Visual Studio.
4. Configure the database connection in `App.config` to match your local SQL Server instance.
5. Ensure the required database and tables are available.
6. Build and run the project.

## Project Status

This project was developed for practical experience with C#, Windows Forms, and SQL Server.
